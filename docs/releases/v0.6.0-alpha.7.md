# Cydetix v0.6.0-alpha.7 development candidate

Date: 2026-09-09

Alpha.7 makes Cydetix a protocol-first, agent-independent local security runtime. The deterministic
security engine, proof model, remediation policy, hostile-repository model, and project boundary
remain unchanged from alpha.6.

## Universal local agent integration

- Every host adapter now declares capabilities, compatibility tier, configuration targets,
  detection, installation, verification, and removal.
- Tier 1 native stdio MCP adapters cover OpenAI Codex, Claude Code, Cursor, GitHub Copilot,
  Windsurf, Gemini CLI, Cline, Roo Code, Continue, Goose, and the explicit Generic MCP escape hatch.
- `cydetix setup` and `cydetix setup --agent auto` detect hosts without executing them.
  `--agent all --yes` configures detected user-scoped hosts and safe project-scoped hosts while
  keeping Generic MCP explicit.
- `cydetix doctor --agents` provides human diagnostics; `--format json` provides a stable,
  schema-backed compatibility report.
- `cydetix mcp-config --format json` prints a validated exact-runtime MCP definition without writes
  or banners.

Skills remain optional behavior enhancements. MCP and the exact deterministic CLI fallback work
without a skill. Persistent execution uses an absolute Node executable and absolute Cydetix JS
entrypoint; it never relies on npm, npx, a downloader, PATH resolution, or network installation.

## Validation focus

The candidate adds adapter lifecycle, preservation, invalid-config, path-space, platform,
canonical-root, symlink, exact-runtime, package-manager trap, doctor, Generic MCP, three-tool,
boundary, and packed-install regressions. Packed validation includes a conflicting older alpha.6
launcher on `PATH` and proves the candidate runtime still reports and enforces alpha.7 exactly.

Host-provided MCP roots are not consumed in alpha.7. The configured canonical Cydetix project root
remains authoritative, and client capabilities cannot widen it. Remote HTTP MCP is intentionally out
of scope.

No tag, npm publication, npm dist-tag change, or GitHub release is performed by this candidate.
