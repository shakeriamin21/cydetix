# Cydetix v0.6.0-alpha.6 release candidate

Date: 2026-09-09

This candidate fixes AI-agent execution without changing the deterministic security engine, rule
semantics, remediation classifications, or release controls.

## Runtime and boundary corrections

- Explicit `cydetix setup` now accepts only the currently executing persistent Cydetix package after
  canonical identity, exact version, regular-file, non-symlink entrypoint, package-boundary, Node
  executable, and ephemeral `_npx` cache checks.
- Generated MCP configuration invokes the exact Node executable and exact Cydetix JS entrypoint
  directly with `mcp --project-root <canonical-root> --require-version 0.6.0-alpha.6`.
- MCP startup checks the required version before reading requests and maintains its own canonical
  project boundary independently of process `cwd`.
- Agent subprocess scans support strict JSON/SARIF output, piped stdio, explicit project roots, and
  `CYDETIX_AGENT_SUBPROCESS=1` without setup prompts or host configuration writes.
- The skill fallback permits only setup-managed direct argv and forbids npm/npx invocation, network
  access, package installation, privilege elevation, PATH widening, and sandbox escape.

## Validation scope

The release candidate includes source, MCP, integration, non-TTY CLI, path-boundary, setup
idempotency/removal, runtime-verification, no-package-manager-spawn, and packed-install regressions.
Cross-platform generated definitions are process argv arrays with no shell quoting. Hosted Windows,
Ubuntu, and macOS Node 22/24 results remain release-workflow evidence and must not be claimed until
those jobs run.

No tag, npm publication, GitHub release, or dist-tag movement is performed by this preparation.
