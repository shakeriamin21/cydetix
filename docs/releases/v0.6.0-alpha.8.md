# Cydetix v0.6.0-alpha.8 development

`0.6.0-alpha.8` is an unpublished development line based on the immutable `v0.6.0-alpha.7` release.
No alpha.8 tag, npm publication, GitHub release, or dist-tag change is part of this phase.

The phase adds the Trust Assurance model, proof-carrying findings, explicit analysis completeness,
reproducible scan manifests, deterministic trust fingerprints, auditable suppressions, a monotonic
remediation ceiling, and `rules`/`trust` inspection commands.

Batch 1 adds bounded high-confidence application-dataflow coverage for supported SQL injection, OS
command injection, path traversal, and SSRF patterns in JavaScript/TypeScript and Python server
contexts. All four rules have a `REVIEW_REQUIRED` remediation ceiling. Unsupported or incomplete
behavior remains explicit and does not become proof of security.

See `docs/security/RULE_ADMISSION_GATE.md`, `TRUST_MODEL.md`, `SAFE_FIX_ADMISSION.md`,
`PROOF_MODEL.md`, `RULE_EXPANSION_PLAN.md`, and `RULE_COVERAGE.md` for the exact evidence and
support envelope.
