# Cydetix v0.6.0-alpha.1

**PUBLIC ALPHA CANDIDATE -- NOT PUBLISHED**

This prerelease packages Cydetix's deterministic local application-security analysis, authentication
evidence graphs, npm/GitHub Actions supply-chain analysis, CycloneDX output, and transactional SAFE
remediation preview. It is not production-readiness certification and does not claim complete
vulnerability or framework coverage.

## Highlights

- Offline ordinary scans that do not execute repository programs.
- Narrow evidence-backed JavaScript, TypeScript, Python, Express, and Prisma analysis documented in
  `SUPPORT_MATRIX.md`.
- Explicit online OSV dependency enrichment without source-code transmission.
- Plan-first remediation with one verified SAFE HttpOnly adapter; review-required and architectural
  changes remain plans.
- Authorized verification in a Cydetix-controlled Linux container with network disabled, sanitized
  environment, non-root execution, read-only root filesystem, no-new-privileges, bounded resources,
  and no host Docker socket. Container/runtime trust limitations remain.
- One portable `cydetix` Agent Skill, six setup adapters, and a three-tool first-party MCP server
  with explicit mutation boundaries.
- Zero-config current-project scanning and packed-artifact `npm exec`/global-launcher validation.

## Install

The requested npm coordinate is the exact unscoped `cydetix`, but it is not registered or published.
A registry query returned `E404` on 2026-09-06; this is not a reservation. Limited exact-name web
searches found no obvious active match, but no exclusivity or trademark clearance is claimed.
Publication must stop on any registry/name conflict and may not fall back to a scoped command
without explicit user approval.

## Verification

Release downloads will include SHA-256 checksums, a CycloneDX SBOM, the validation report, and a
machine-readable release manifest. The GitHub workflow is configured to create build and SBOM
attestations; attestation establishes source/build relationships, not vulnerability freedom.

## Important limitations

- Cross-file and framework coverage is deliberately bounded; unsupported cases remain unknown.
- Dependency presence does not prove vulnerable-function reachability.
- SAFE autofix coverage is intentionally small.
- NodeGoat evidence covers six adjudicated Action-pin findings plus one domain-context case; recall
  is not available. BenchmarkPython cases reviewed so far are not applicable and are not negatives.
- Container isolation depends on Docker, the host kernel/runtime, runtime-default seccomp, and a
  reviewed immutable image. It is not a perfect sandbox and is not claimed safe against all
  container escapes.

Read `README.md`, `docs/CLAIMS.md`, `docs/VALIDATION.md`, and `docs/LIMITATIONS.md` before use.
