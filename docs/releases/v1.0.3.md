# Cydetix v1.0.3 maintenance release

Version `1.0.3` preserves the stable CLI, MCP, security rules, remediation authority, and package
contracts. It makes release evidence subjects immutable: the trusted workflow binds Gitleaks review
output to a content-addressed file so later verification cannot change an existing evidence record.

The annotated `v1.0.2` tag remains immutable at `505b2e55a8bd48c180f8d15212059c250a1b726a`. Its
trusted run `37187353787` failed before npm or GitHub Release publication. `v1.0.1` is the previous
successfully published stable release; `v1.0.3` supersedes the failed publication attempt.

Existing limitations remain: `UNKNOWN` and `TRUNCATED` are not proof of security; language, parser,
framework, dependency, corpus, host-integration, performance, and remediation coverage remain
bounded as documented in `docs/LIMITATIONS.md`. No universal security or performance claim is made.
